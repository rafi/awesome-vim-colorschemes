> A dark Neovim / Vim colorscheme for the GUI and 256 / true-color terminals.

## Features

- No configuration is required to start using it.
- Supports 256 color terminals.
- Supports Neovim's built-in [language server client](https://neovim.io/doc/user/lsp.html).
- Supports [lightline.vim](https://github.com/itchyny/lightline.vim) theme.
- Supports [nvim-treesitter](https://github.com/nvim-treesitter/nvim-treesitter).
- Supports LSP Semantic highlights.
- Fast loading with precompiled colorscheme files generated by Rust.
- Maintainable and consistent color definitions powered by a Rust-based generator.

Check [here](#supported-filetypes--plugins) for a list of supported file types and plugins :muscle:

## Installation

### Using [vim-plug](https://github.com/junegunn/vim-plug)

```vim
Plug 'wadackel/vim-dogrun'
```

### Using [lazy.nvim](https://github.com/folke/lazy.nvim)

```lua
{
  'wadackel/vim-dogrun',
  lazy = false,
  priority = 1000,
}
```

## Usage

Add the following settings to your `$MYVIMRC` (`.vimrc` or `init.vim`).

```vim
colorscheme dogrun
```

### Options

#### lightline theme

If you want, specify `dogrun` to `colorscheme`.

```vim
let g:lightline = {
  \ 'colorscheme': 'dogrun',
  \ }
```

#### vim-clap theme

If you want, specify `dogrun` to `g:clap_theme`.

```vim
let g:clap_theme = 'dogrun'
```

## Other Tools

In the future, there may be a possibility to offer separate themes, but for now, we will introduce the inline themes for each tool.

### [WezTerm](https://github.com/wez/wezterm)

![WezTerm](./docs/images/wezterm.png)

Copy `wezterm/dogrun.toml` to WezTerm's colors directory:

```bash
cp wezterm/dogrun.toml ~/.config/wezterm/colors/dogrun.toml
```

Then in `~/.config/wezterm/wezterm.lua`:

```lua
return {
  color_scheme = "dogrun",
}
```

### [fzf](https://github.com/junegunn/fzf)

![fzf](./docs/images/fzf.png)

`~/.zshrc` or `~/.bashrc`

<!-- fzf:start -->
```bash
export FZF_DEFAULT_OPTS='--color=fg:#8085a6,bg:#222433,hl:#bdc3e6,fg+:#8085a6,bg+:#363e7f,hl+:#bdc3e6,info:#929be5 --color=prompt:#32364c,pointer:#b871b8,marker:#b871b8,spinner:#73c1a9,header:#32364c,border:#32364c,gutter:-1'
```
<!-- fzf:end -->
